## 問題7 shou07-l2-real-n4（Level 2・計算）N=4 の実離散フーリエ級数展開

判定: (1) ○ 記 ／ (2) ◎ ／ (3) ○ 記 ／ (4) ◎

### (1) ○（記）
- 積和公式で sin の和にし、z1 = e^{i2π(μ+ν)/N}、z2 = e^{i2π(μ−ν)/N} とおいて Σ(1/2)Im(z1^n + z2^n) に直すまでは正しい。
- 写真の上部右の書き込み「μ+ν や μ−ν が N の倍数でも倍数でなくても虚部は 0」で結論を出しているが、なぜ虚部が 0 かの根拠（和の値）が書かれていない。足すべき一行は
  S_p = Σ_{n=1}^{N} e^{i2πpn/N} = N（p が N の倍数：各項が 1）、0（それ以外：等比級数で z^N = 1 より z(1−z^N)/(1−z) = 0）で、どちらも実数なので Im S_p = 0。
  （「1 − z1」と書きかけて消した跡があるので、等比級数の式を最後まで書けばよかった。）
- 読み直す箇所: 解答 問題7 ① の S_p の場合分け、問題5（rootsum）(1) の解答。

### (2) ◎
- A = (−1/4, 0, −1/4, 1/2)、B = (1/4, 0, −1/4, 0) すべて正しい。A_μ の式の角度は 2πμn/4 を πμn/2 に書き直してあり、値の計算も πμn/2 で行っている。

### (3) ○（記）
- z = e^{iπ/2} とおいた 2U† の行列（指数を z^4 = 1 で 0〜3 に減らしたもの）、2U†f = (−i−1, 0, i−1, 2)、f̂ = (−1/2 − i/2, 0, −1/2 + i/2, 1) はすべて正しい。
- 写真の中ほど下の「(1/2)Re f̂_μ = (−1/4, 0, −1/4, 1/2)」「−(1/2)Im f̂_μ = (1/4, 0, −1/4, 0)」は (2) の A_μ・B_μ と一致しているが、「よって Re f̂_μ = 2A_μ、Im f̂_μ = −2B_μ が成り立つ」という確認の一行が無い（問題は「確かめよ」なので結論を書く）。
- 細かい点: 1行目の (e^{−iπμn/2})_{nμ} は (U†)_{μn} の成分なので添字は μn の順。

### (4) ◎
- Parseval: Σ|f̂_μ|^2 = 1/2 + 0 + 1/2 + 1 = 2 = |f|^2（(3) の右に「(4)」として記載）。
- 逆変換: 0 になる係数（A2・B2・B4）を消してから n = 1〜4 を代入し、1, 1, 0, 0 を再現。n = 2, 4 で sin の項を省いたのも sin(kπ) = 0 で正しい。

### 読み直す箇所
- 解答 問題7 ① の S_p（1の N 乗根の和）の場合分けと、それが実数であること。
