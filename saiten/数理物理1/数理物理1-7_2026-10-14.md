## 問題6 shou07-l2-symmetric（Level 2・導出）添字 μ を対称にとった離散フーリエ級数展開

判定: (1) ○ 記 ／ (2) ▲ 立 ／ (3) △ 計 ／ (4) △ 計

### (1) ○（記）
- (U†U)_{μν} = (1/N) Σ_n e^{i2πn(ν−μ)/N} の立式と、μ = ν／μ ≠ ν の場合分け、z^N = 1 から 0 とする流れは正しい。
- 抜けている根拠: μ ≠ ν のとき z = e^{i2π(ν−μ)/N} ≠ 1 であること。μ, ν が −M〜M にあるので 0 < |ν−μ| ≤ 2M = N−1 となり、ν−μ は N の倍数でない（この問題で列の添字を対称にとった意味がここにある）。
- 細かい点: 写真1枚目の下の「Σ_{n=1}^{N} z^n = (1−z^N)/(1−z)」は z(1−z^N)/(1−z) が正しい（0 になる結論は変わらない）。

### (2) ▲（立）
- 写真1枚目の下から2つ目の式「Σ_{n=1}^{N} U_{μn}(U†)_{nν} = Σ_{n=1}^{N} (1/N) e^{i2πn(μ−ν)/N}」は、n について和をとっていて (1) と同じ（の複素共役の）量を計算している。UU† の成分は行の添字 n, m について
  (UU†)_{nm} = Σ_{μ=−M}^{M} U_{nμ} U*_{mμ} = (1/N) Σ_{μ=−M}^{M} e^{i2πμ(n−m)/N}
  で、和は列の添字 μ（−M〜M）についてとる。この問題の U は行が 1〜N、列が −M〜M なので U_{μn} という成分は無い。
- 正しくは、n ≠ m で w = e^{i2π(n−m)/N} ≠ 1、w^N = 1。μ' = μ + M + 1 とずらすと Σ_{μ=−M}^{M} w^μ = w^{−M−1} Σ_{μ'=1}^{N} w^{μ'} = 0。「先ほど同様」では済まず、添字をずらす一手がこの小問の要点。

### (3) △（計）
- 写真1枚目の最下行「f̂_{−μ} = Σ (1/√N) e^{−i2πμn/N} f_n」は、(U†)_{−μ,n} = e^{−i2π(−μ)n/N}/√N = e^{+i2πμn/N}/√N の符号を落としている（書いた式は f̂_μ そのもの）。次の「= (Σ (U†)_{μn} f_n)*」とつながらない。
- また、複素共役をとって f̂_μ* にできるのは f_n が実数だからで、その一言が無い（この小問の要の根拠）。
- 正しくは f̂_{−μ} = Σ e^{i2πμn/N} f_n/√N = (Σ e^{−i2πμn/N} f_n/√N)*（f_n 実数）= f̂_μ*。

### (4) △（計）
- μ < 0 の項を (3) で書き直して ±μ をまとめる方針、a_0 = f̂_0/√N = (1/N) Σ f_n、a_μ = (2/N) Σ cos(2πμn/N) f_n は正しい。
- 写真2枚目の上から3行目「(1/√N)(f̂_μ* − f̂_μ) sin(2πμn/N)」は因子 i が落ちている。e^{−iθ}f̂* + e^{iθ}f̂ = (f̂ + f̂*) cos θ + i(f̂ − f̂*) sin θ = 2 Re f̂ cos θ − 2 Im f̂ sin θ。
- 写真2枚目の b_μ の行: b_μ = −(2/√N) Im f̂_μ までは正しいが、Im(Σ e^{−i2πμn/N} f_n/√N) = −(1/√N) Σ sin(2πμn/N) f_n なので
  b_μ = +(2/N) Σ sin(2πμn/N) f_n（書いた答えは符号が逆）。
  確認: N = 3、f = (1, 0, 0) で正しい符号なら n = 1, 2, 3 で 1, 0, 0 を再現し、書いた符号では 0, 1, 0 になる。
- 細かい点: a_0, a_μ, b_μ が実数であること（(3) で μ = 0 とおくと f̂_0 は実数）にも一言ほしい。
