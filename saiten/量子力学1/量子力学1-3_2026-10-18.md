## 問題4 kai03-l2-gauss（Level 2・計算）ガウス型の波束の規格化・⟨p̂⟩・確率流

判定: (1) ◎ ／ (2) △ 計 ／ (3) ○ 計

- (1) ◎：A = (2πσ²)^{−1/4}。正しい。
- (2) △（計）：p2 右上「∂/∂x(A exp(−x²/4σ² + ik₀x)) = ik₀ A exp(…)」で、ガウス因子の微分 −x/(2σ²) の項が落ちている。正しくは
  ∂ψ/∂x = (−x/(2σ²) + ik₀)ψ、ψ*p̂ψ = (iħx/(2σ²) + ħk₀)|ψ|²。
  第1項は奇関数なので積分が0になり、⟨p̂⟩ = ħk₀ になる。答えは合っているが、それは落とした項がたまたま奇関数で消えるからで、この問題の要（偶関数・奇関数に分けて積分する）が抜けている。
- (3) ○（計）：(2) と同じ誤った微分から「ψ*∂ψ/∂x = ik₀A²exp(−x²/2σ²)」としている。正しくは (−x/(2σ²) + ik₀)|ψ|² で、落ちた項は実数なので虚部（したがって j）には効かない。j(x,0) = ħk₀|ψ|²/m と ∫j dx = ħk₀/m = ⟨p̂⟩/m は正しい。なお「k₀A² = (k₀²/(2σ²π))^{1/2}」は k₀<0 で符号が合わないので、k₀/√(2πσ²) と書く。
- 読み直す箇所: ヒント2・解答 問題4 ②(2) の ∂ψ/∂x = (−x/(2σ²) + ik₀)ψ と、つまずきポイント。

## 問題5 kai03-l2-reflect（Level 2・計算）入射波と反射波の確率流

判定: (1) △ 立 ／ (2) ○ 記 ／ (3) △ 計

- (1) △（立）：p3 左上「ψ*∂ψ/∂x = A²(e^{−ikx} + R e^{ikx})(…)」で、ψ* の中の R を R* にしていない（A も A* になっていない）。問題文で A・R は複素数である。R を実数とした計算なので、交差項が「2iR sin(2kx)」になり、j = (ħk/m)A²(1 − R²) になった。R が複素数なら Im(ikA²·2iR sin2kx) は x に依存してしまうので、この計算では「j が x によらない」ことは示せていない。正しくは
  ψ*∂ψ/∂x = ik|A|²(1 − |R|² − R e^{−2ikx} + R* e^{2ikx})、z = R e^{−2ikx} とおくと交差項 z* − z は純虚数 → ik を掛けると実数で虚部に寄与しない → j = ħk|A|²(1 − |R|²)/m。
- (2) ○（記）：ρ = |A|²[1 + |R|² + 2|R|cos(2kx − δ)] は正しい（ここでは R* = |R|e^{−iδ} を正しく使えている。A² は |A|²）。連続の式の説明は「∂ρ/∂t = 0 だから ∂j/∂x = 0」で骨格は正しいが、ρ が t によらない理由（時間の因子が全体の e^{−iωt} だけ）と、「連続の式が結びつけるのは ρ の t 微分と j の x 微分なので、ρ の x 依存は j を縛らない」の一言が無い。
- (3) △（計）：j_in = ħk|A|²/m、j_ref = −ħk|A|²|R|²/m、j = j_in + j_ref と、図つきの意味づけ（壁へ向かう流れと反射した流れ）は正しい（ただし A²R² ではなく |A|²|R|²）。R = −1 のときの ρ を「2A²(1 + cos(2kx − δ))」で止めている。R = −1 は |R| = 1、δ = π なので、ρ = 2|A|²(1 − cos2kx) = 4|A|²sin²kx（節のある定在波）まで求める。j = 0 は正しい。
- 読み直す箇所: 解答 問題5 ②(1) の z = R e^{−2ikx} を使った交差項の扱い、②(3) の R = −1 で ψ = 2iA sin(kx)e^{−iωt}。

## 問題6 kai03-l2-box（Level 2・計算）2つの定常状態の重ね合わせと連続の式の積分形
